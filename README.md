# Генератор солнечной системы (Университетский проект)

Консольное приложение генерации и визуализации солнечной системы

## Функционал
* Реализованы классы для звезд: `Звезда основной последовательности`, `Красный гигант`, `Белый карлик`, `Пульсар`
* Реализованы классы для планет: `Планета земного типа`, `Газовый гигант`
* Реализован класс для спутников
* Реализованы классы для свободных объектов: `Комета`, `Астероид`
* Реализован класс для звездной системы
* Реализованы классы для форматированного вывода информации об объектах системы
* Реализованы классы-расширения для удобной работы с системой
* Реализованы классы настроек системы: `Ограничения генерации`, `Шансы генерации`, `Настройки визуализации`
* Реализованы классы для визуализации системы
* Реализована сериализация системы и настроек

## Требования

- [.NET 10.0 SDK](https://microsoft.com) или новее
- C# 14

## Как развернуть проект

1. **Клонируйте репозиторий:**
   ```
   git clone https://github.com/Krakennn001/starsystem-simulator
   cd StarSystemSimulator
   ```

2. **Соберите и запустите проект:**
   ```
   dotnet run
   ```

## Структура проекта
* `Program.cs` - точка входа, цикл симуляции
* `Descriptions` - классы для реализации форматированного вывода текста в консоль
* `Entities` - классы небесных тел
* `Enums` - вспомогательные перечисления типов объектов
* `Extensions` - расширения для некоторых типов данных
* `Generators`- генераторы отдельных объектов и всей системы
* `Services` - сервисы (сериализация, исключения, утилиты)
* `Settings` - классы настроек проекта
* `UI` - классы реализации пользовательского интерфейса
